# FarmSmart Backend

FastAPI backend for FarmSmart.

## What it provides

- OTP-based signup and signin
- Role-restricted access for farmers and agriculture officers
- JSON file storage for local users and OTPs
- Panchayat, crop and recommendation APIs
- Live weather fetch from Open-Meteo by Panchayat coordinates
- CSV import helper for official LGD/Census-derived location data

## Run

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Then open:

```text
http://127.0.0.1:8000/docs
```

## Seeded Accounts

Seeded users:

```text
Farmer
Mobile: 9876543210
Role: farmer

Agriculture Officer
Mobile: 9000011111
Role: officer
```

OTP is generated by `/auth/request-otp` and returned in the response for local development. In production, the OTP should be sent using SMS and never returned to the frontend.

## Storage Note

This backend stores local development data in `data/store.json`. For deployment, move users, sessions, OTPs and location records to a database.

## Import Official Location Data

Prepare a CSV with this schema:

```text
id,state,district,mandal,name,latitude,longitude,soil_type,major_crops
```

Use `|` between crops:

```text
tomato-village,Andhra Pradesh,Chittoor,Madanapalle,Example Village,13.55,78.50,Red loamy soil,Tomato|Groundnut
```

Run:

```bash
python -m app.import_locations_csv data/location_schema.csv data/locations.json
```

After import, the API will read `data/locations.json` instead of the seeded Panchayat list. For final accuracy, use official LGD administrative data and verified latitude/longitude coordinates. Do not hand-generate village lists.

For production:

- Use PostgreSQL, Firebase or Supabase.
- Store official LGD Panchayat/village data in database tables.
- Send OTP through SMS provider.
- Add JWT/session tokens.
- Hash any password data if passwords are later added.

## Phone OTP Provider

The frontend includes a Firebase Phone Auth integration in `firebase-config.js`.

To make OTP arrive on a real phone:

1. Enable Phone provider in Firebase Authentication.
2. Add your Firebase web app config to `../firebase-config.js`.
3. Add the deployed frontend domain in Firebase authorized domains.
4. Set SMS region policy to allow India if you are testing Indian numbers.

For production, never return OTP values from backend APIs. Send OTP through Firebase, MSG91, Twilio or another SMS provider.
